# Dycore Testbed

This repository initializes the structure for a future dynamical core testbed.

## Getting Started
- Populate source modules under `src/`.
- Add kernel templates in `templates/` and configuration samples in `configs/`.
- Extend documentation in `docs/` as architecture decisions are finalized.

## Project Layout
- `docs/` – project documentation and design notes.
- `templates/` – placeholders for kernel and configuration templates.
- `tools/` – helper scripts for development and maintenance.
- Additional directories are reserved for tests, data, benchmarks, and CI workflows.
